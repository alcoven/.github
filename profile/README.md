# Alcoven

A project that remembers, for everyone on it. An Alcoven project holds your team's brief, documents, tasks and notes, and the people on it and the AIs they use read from it and write back to it.

- **Open it from the AI you use.** Add `https://app.alcoven.co/mcp` to Claude, to ChatGPT on plans that allow it, or to any other AI app that lets you add an MCP server, and choose the project when you sign in. Setup: [alcoven.co/connect](https://alcoven.co/connect).
- **Or clone it with git.** Every project is a git repository. Clone it from Claude Code, Codex or a terminal, then pull, change and push.
- **Every change has a name.** What your AI writes goes on the project under your name, so everyone sees who changed what and when.

One project and up to five people writing to it, free. No card. [alcoven.co](https://alcoven.co) · MCP Registry: `co.alcoven/alcoven`
